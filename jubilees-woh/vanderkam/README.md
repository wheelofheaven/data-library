# VanderKam Ge'ez (Beta maṣāḥǝft transcription) — NOT YET A COMPLETE SOURCE

`geez-N.json` holds Ran HaCohen's transcription of VanderKam, *The Book of Jubilees: A Critical Text*
(CSCO 510, 1989), from Beta maṣāḥǝft LIT1697Jubilees (CC BY-SA 4.0), parsed by `scripts/resource_jubilees.py`.

The transcription is **abridged in places**. Jubilees 1:23 lacks the clause on circumcising the
foreskin of the heart and creating a holy spirit, which the Charles 1895 Ethiopic edition prints
(archive.org `CharlesEthiopicJubilees`, PDF page 39). A chapter 1 pilot translation flagged likely
shortfalls in 1:4, 1:8, 1:10, 1:13, 1:23, 1:26 and 1:29.

Before any chapter is translated from here, collate it against a printed edition (Charles 1895 or
Dillmann 1859, both public domain on archive.org) and fill the gaps, recording each addition.
